    Priority 1 — Highest impact (dashboard home + billing)

    GET  /api/internal/admin/system/status
         → return platform health: { db, redis, queues, services }
    GET  /api/internal/admin/billing/overview
         → return { totalRevenue, mrr, activeSubscriptions, totalUsers, creditsIssued }
    GET  /api/internal/admin/payment-transactions/revenue
         → return revenue time-series data
    GET  /api/internal/admin/subscriptions
         → return list of all user subscriptions
    GET  /api/internal/admin/subscriptions/stats
         → return { active, cancelled, trialing, pastDue }
    PATCH /api/internal/admin/subscriptions/:id
          body: { action: "cancel" | "reactivate" }

    GET    /api/internal/admin/credentials/status

    GET    /api/internal/admin/credentials/:service
    PUT    /api/internal/admin/credentials/:service
           body: service-specific key/value fields
    DELETE /api/internal/admin/credentials/:service
    POST   /api/internal/admin/credentials/:service/test
           → test connectivity, return { success, message }

    Priority 3 — Notifications & KYC

    GET    /api/internal/admin/notifications
           → paginated list of sent broadcasts

    GET    /api/internal/admin/users/kyc-queue
