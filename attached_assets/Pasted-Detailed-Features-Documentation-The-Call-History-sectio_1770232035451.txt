Detailed Features Documentation
The Call History section in Retell AI provides comprehensive call monitoring, analysis, and management capabilities. Here's a complete breakdown of all features:

1. Call History Overview
The Call History page displays all past voice and chat interactions in a sortable, filterable table format with:

Location: Monitor section in left sidebar

Pagination: Shows "Page 1 of 1 - Total Session: 1" with navigation controls

Bulk Actions: 50/page display option

Export Functionality: Export call data for external analysis

2. Top Toolbar Features
Date Range Selector
Filter calls by custom date ranges

Quick access to time-based filtering

Filter Button
​
Comprehensive filtering with 4 tabs:

Base Tab - Core Call Attributes:
Agent: Filter by specific AI agent(s)

Call ID: Search by unique call identifier

Batch Call ID: Filter bulk/batch call sessions

Type: Channel type selection (web_call, phone_call, etc.)

Duration: Filter by call length

From: Caller phone number/ID

To: Recipient phone number/ID

User Sentiment: Filter by detected sentiment (Positive, Neutral, Negative)

Disconnection Reason: Why call ended (user_hangup, agent_hangup, error, voicemail, IVR, etc.)

Call Status: Session state (ended, in_progress, error)

Call Successful: Success/failure status

E2E Latency: End-to-end response time filtering

Post Call Analysis Tab
​
Filter based on post-call analytics

Conditional filters based on selected agent

Metadata Tab

Integration data filtering

4. Call History Table Columns Explained
Time
Full timestamp with timezone: "2026-01-25 12:18:32 +04"

Sortable column

Duration
Call length in MM:SS format: "0:18"

Helps identify abandoned/short calls

Channel Type
web_call: Browser-based calls (WebRTC)

phone_call: PSTN telephony calls

sip: SIP trunk calls

Cost
Real-time cost calculation: "$0.035"

Based on duration, LLM usage, TTS/STT costs

Info button for cost breakdown

Session ID
Unique call identifier: "call_3f241725beb5b099df7574b880b"

Used for API queries and debugging

Clickable to open detail view

End Reason
​
Why the call ended:

user hangup - Customer disconnected

agent_hangup - AI terminated call

error - Technical failure

voicemail - Voicemail detected

ivr_detected - IVR system detected

max_duration - Time limit reached

inactivity - No user input timeout

Session Status (optional column)
ended - Completed normally

in_progress - Currently active

error - Failed or crashed

User Sentiment (optional column)
​
AI-detected emotional state

Neutral, Positive, Negative

Based on speech patterns and conversation content

Additional Optional Columns
From/To: Phone numbers or identifiers

Direction: Inbound/Outbound

Session Outcome: "Unsuccessful", "Successful"

End to End Latency: Response time metrics
