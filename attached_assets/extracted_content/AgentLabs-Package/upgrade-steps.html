AgentLabs Upgrade Guide

Follow these steps to upgrade from an older version to the latest version while preserving your database data.

⚠️ Important: Always backup your database before upgrading. Your data will be preserved, but backups protect against unexpected issues.

Pre-Upgrade Checklist

1 Backup Your Database

Export your PostgreSQL database:

pg_dump $DATABASE_URL > agentlabs_backup_$(date +%Y%m%d).sql
2 Note Your Environment Variables

Save a copy of your current secrets and environment variables:

  • DATABASE_URL
  • ELEVENLABS_API_KEY (pool credentials)
  • TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN
  • STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET
  • OPENAI_API_KEY
  • Any other custom secrets
3 Stop Running Services

Stop the application to prevent conflicts during upgrade.

Upgrade Steps

4 Download Latest Version

Replace your source files with the new version from CodeCanyon. Keep these folders intact:

  • /uploads - User uploaded files
  • /.env or secrets - Your configuration
5 Install Dependencies 
npm install
6 Run Database Migrations

This will update your database schema without losing data:

npm run db:push

Note: Drizzle ORM safely adds new columns/tables while preserving existing data.

7 Build Plugins (If Using) 
node scripts/build-plugins.js
8 Restore Environment Variables

Re-add any secrets that were removed during the file replacement.

9 Start the Application 
npm run dev

Post-Upgrade Verification

10 Verify Your Data
  • Login with existing admin/user accounts
  • Check agents, campaigns, and call history
  • Verify payment gateway connections
  • Test ElevenLabs credential pool
  • Confirm webhook endpoints are working
✅ Upgrade Complete!

Your AgentLabs installation is now running the latest version with all your existing data preserved.

Troubleshooting

Database connection errors: Verify DATABASE_URL is correctly set.

Missing tables/columns: Re-run npm run db:push

Plugin errors: Rebuild plugins with node scripts/build-plugins.js

Need to rollback: Restore from your backup: psql $DATABASE_URL < agentlabs_backup_YYYYMMDD.sql
