For developers

Ship a voice agent in a few lines

A clean REST + WebSocket API, webhooks for every call event, and SDKs for the stacks you already use. Bring your own LLM, voices and telephony.

create_agent.ts 
import { Loop9 } from "@loop9/sdk";

const loop9 = new Loop9(process.env.L9_KEY);

const agent = await loop9.agents.create({
  voice: "ava-natural",
  knowledge: ["https://acme.com/help"],
  actions: ["book_meeting", "transfer"],
  handoff: "when_unsure",
});

loop9.numbers.attach("+1 555 0199", agent.id);
// your line is now answered by AI
